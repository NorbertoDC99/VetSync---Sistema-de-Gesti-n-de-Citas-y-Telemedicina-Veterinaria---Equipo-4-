# Sistema de Gestión de Citas y Telemedicina Veterinaria 🐾

Este es un proyecto web sencillo y amigable diseñado para gestionar y registrar citas veterinarias, incluyendo la opción de especificar si la consulta es presencial o por telemedicina.

## 🚀 Características
*   **Interfaz Amigable:** Diseño moderno con tonos crema y beige claro, bordes redondeados y estructura fácil de usar.
*   **Todo en Uno:** El proyecto está consolidado en un único archivo (`index.html`) que contiene la estructura, el diseño y la lógica.
*   **Registro Dinámico:** Permite registrar los datos del paciente (mascota, dueño, fecha, hora, motivo y modalidad) y visualizarlos inmediatamente en una tabla.
*   **Exportación a Excel:** Integración con la librería `SheetJS` para extraer la tabla de citas registradas a un archivo `.xlsx` con formato ajustado.

## 🛠️ Tecnologías Utilizadas
*   HTML5
*   CSS3 (Integrado)
*   JavaScript (Integrado, Vanilla JS)
*   SheetJS (CDN)

## ⚙️ Cómo ejecutar el proyecto
1. Clona este repositorio o descarga los archivos.
2. Abre el archivo `index.html` en tu navegador web de preferencia. No es necesario instalar dependencias ni servidores locales.
3. Registra citas desde el formulario y utiliza el botón "Exportar a Excel" para probar la funcionalidad de descarga
